2.
ps -eo pid,ppid,stat,pri,nice,%mem,%cpu,tty,cmd

    -e: wyświetla wszystkie procesy w systemie
    -o: pozwala dostosować wyświetlane kolumny
    PID: identyfikator procesu
    PPID: identyfikator procesu rodzica
    STAT: stan procesu
    PRI: priorytet procesu
    NICE: nice procesu
    %MEM: procent użycia pamięci
    %CPU: procent użycia CPU
    TTY: terminal, do którego jest podpięty proces
    
ps -p 4748 -o pid,ppid,state,pri,nice,%mem,%cpu,tty,cmd
    
ps axjf   #wyswietla wszystkie procesy (nawet te na innych terminalach)

$ cat > test.c
#include <stdio.h>

{
    printf("Hello, World!\n");
    return 0;
}
^D
$ gcc -Wall -pedantic test.c
$ ./a.out

Wall: Włącza wszystkie ostrzeżenia kompilatora.
-pedantic: Wymusza standard C, zgłaszając ostrzeżenia dla kodu, który jest niezgodny z wybranym standardem.
